# Ansh Thakur — Portfolio

Personal portfolio of Ansh Thakur — full-stack web developer & database engineer.
Built with React, Vite, TypeScript, Tailwind CSS and Three.js.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build      # outputs to dist/
```

## Deploy
Deploys to Vercel out of the box (see vercel.json). Import the repo in Vercel and it auto-detects Vite.
